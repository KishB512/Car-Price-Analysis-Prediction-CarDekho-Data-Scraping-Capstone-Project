# 🚗 Car Price Analysis & Prediction — CarDekho Data Scraping Capstone Project

## 📌 Project Overview
This capstone project focuses on **scraping, analyzing, and deriving insights** from used car listings available on the CarDekho website. The goal is to understand the key factors that influence car prices and build a structured dataset suitable for data analysis and machine learning applications.

This project demonstrates the complete **data science pipeline** — from data collection to preprocessing, analysis, and visualization.

---

## 🎯 Objectives
- Scrape real-world used car data from CarDekho
- Clean and preprocess raw scraped data
- Perform exploratory data analysis (EDA)
- Identify key features affecting car prices
- Prepare dataset for future predictive modeling

---

## 🛠️ Tech Stack
- **Python**
- BeautifulSoup / Requests (Web Scraping)
- Pandas & NumPy (Data Processing)
- Matplotlib & Seaborn (Visualization)
- Jupyter Notebook

---

## 📊 Dataset Features
The scraped dataset includes important car attributes such as:

- Car Name / Model
- Price
- Manufacturing Year
- Fuel Type
- Transmission Type
- Kilometers Driven
- Ownership Type
- Location

---

## 🔎 Project Workflow

### 1️⃣ Data Scraping
- Extracted car listings from CarDekho using Python web scraping tools.
- Automated data collection across multiple pages.

### 2️⃣ Data Cleaning
- Removed duplicates and missing values
- Converted price and mileage into numerical formats
- Standardized categorical features

### 3️⃣ Exploratory Data Analysis
- Price distribution analysis
- Fuel type vs price comparison
- Ownership impact on pricing
- Relationship between age of car and price

### 4️⃣ Visualization
- Bar charts, histograms, and scatter plots
- Trend analysis using visual insights

---

## 📈 Key Insights
- Newer cars tend to have significantly higher resale value.
- Diesel cars generally show higher average prices.
- Lower kilometers driven strongly correlates with higher price.
- Ownership count impacts resale price.
